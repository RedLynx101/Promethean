## What's real in the emitted code

- **Zod schemas** at every external boundary. Malformed webhook body → Zod throws before any LLM call.
- **HMAC verification** on the webhook receiver, per `vault/integrations/integration-webhook-receiver.md`.
- **Governance middleware** (`src/governance.ts`, 180 lines) implementing all 8 `governanceConfig` fields: cost accumulator + hard `CostLimitExceeded` throw, latency timer + `latency_spike` alert, `executionTimeoutMs` via `AbortController`, retry-with-backoff with jitter, structured verbose logging to stdout, autosnapshot to `./snapshots/<executionId>/`, alert fan-out stub to configured channels.
- **Five edge-type semantics** exercised by the graph runtime: `default` (sequential), `parallel` (Promise.all), `conditional` (severity gate), `error` (classify → fallback), `loop` (reject-back-to-classify, scaffold terminates but the semantics are wired).
- **HumanGate** with file-based approval signal (proposal written to disk, poll loop, 4h timeout). Production swap-path to Slack approval-button documented inline.
- **Four per-node `errorHandling` strategies** honoured: `alert-and-fail` (validate, fallback, end), `fallback-to-l0` (classify), `retry-with-backoff` (labels, assign, page, comment), `alert-and-skip` (draft; post-comment falls back to a generic ack when draft is skipped).

## Reproduction recipe

```bash
# From repo root:
cd out/github-issue-triage
pnpm install --ignore-workspace
pnpm run typecheck    # clean
pnpm test             # 4/4 passed
```

To regenerate (re-emit after re-approving the workflow in the UI):

1. In the Promethean UI: design + approve the workflow through all four phases.
2. Click **Build** on the workflow detail page → pick `langgraph-js` → `POST /api/workflows/:id/emit` writes a new manifest to `emit-requests/`.
3. Open a harness session (Claude Code with `.mcp.json` auto-wired). Paste:
   > *Read `skills/emit.md` and process `emit-requests/<newest>.json`. Use the `promethean-vault` MCP tools to read every integration note for tools referenced in the workflow. Generate code into the manifest's `targetDir`. Write `EMIT_MANIFEST.json` when done.*
4. Compare `out/<workflow-slug>/` against any previous version; the `promethean.json` diff shows exactly what changed in the approved workflow.
